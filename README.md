# Finaxis

Finance-themed field journal for a Master's in AI Engineering.

## Run locally

```sh
npm install
npm run dev
```

Open `http://localhost:4321`.

## Add a weekly update

Create a Markdown file in `src/content/updates` using an existing post as template. Update member placeholders in `src/data/members.ts` and challenge details in `src/data/site.ts`.
